Networking & Delivery — 4 topics

  1. VPC, subnets & routing

    Your own private network in AWS. Public subnets have a route to an internet gateway; private subnets do not, and reach out through a NAT gateway instead. Anything holding data belongs in a private subnet with no public IP at all.

  2. Security groups vs NACLs

    Security groups are stateful firewalls attached to resources — return traffic is allowed automatically. Network ACLs are stateless and attached to subnets, so you must allow both directions. Almost all day-to-day work is security groups.

  4. CloudFront & the edge

    The CDN. Caches your content at edge locations near users, terminates TLS there, and cuts both latency and origin load. Pair it with S3 for static assets and it is the cheapest performance win available.
