Storage & Data — 5 topics

  1. S3 — object storage

    Effectively unlimited durable storage for files, addressed by key rather than path. Storage classes trade retrieval speed for cost, lifecycle rules move old objects automatically, and pre-signed URLs grant time-limited access without your server touching the bytes.

  2. EBS vs EFS — block vs file

    EBS is a virtual disk attached to one instance; EFS is a shared filesystem many instances can mount. The mistake is reaching for either when S3 would do — object storage is cheaper, and it is the right answer for anything you serve to users.

  3. RDS — managed relational databases

    Managed Postgres or MySQL: AWS handles backups, patching, and failover to a standby in another AZ. Multi-AZ is for availability, read replicas are for read scale — they are different features and interviews like the distinction.

  4. DynamoDB — managed NoSQL

    Single-digit millisecond key-value and document storage at any scale — provided you design the partition key around your access patterns, because you cannot query what you did not model. The opposite discipline from a relational schema.
