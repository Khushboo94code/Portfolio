Images

docker push user/app:tagPublish to a registry

Cleanup

Disk fills up quietly. system prune -a is the one that actually reclaims space — and the one that deletes images you still wanted.

CommandDoes
docker system dfWhat is using disk
docker system pruneRemove stopped containers, unused networks, dangling images
docker system prune -a --volumesRemove everything unused, volumes included — destructive
docker image prune -aRemove all unreferenced images
docker container pruneRemove stopped containers

Dockerfile instructions

InstructionDoesWatch out for
FROMBase imagePin a version; :latest is mutable
WORKDIRSet and create the working directoryUse it instead of RUN cd
COPYCopy files from build contextCopy requirements before source for cache hits
ADDCopy, plus URL fetch and auto-extractPrefer COPY — ADD surprises people
RUNExecute at build timeChain with && to avoid extra layers
ENVSet an environment variableBaked into the image — never secrets
ARGBuild-time variableVisible in docker history
EXPOSEDocument a portPublishes nothing — -p does that
USERSwitch userSet a non-root user before CMD
HEALTHCHECKDefine readinessRequired for service_healthy in Compose
