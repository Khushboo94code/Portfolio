  3. Hashing — maps & sets

    The single highest-leverage tool in interviews: trading memory for time to turn an O(n²) scan into O(n). Recognising "have I seen this before?" or "group these by a key" as a hash problem is most of the battle.

  5. Binary search

    Not just searching a sorted array — the real skill is binary searching the answer: when a problem asks for a minimum or maximum value and you can cheaply test "is X feasible?", the search space is the answer range. Write one template and reuse it everywhere.
