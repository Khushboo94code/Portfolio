Core Patterns — 4 topics

Four shapes that cover a large fraction of array and string questions. Learn to spot them from the problem statement.

  1. Two pointers

    Two indices moving through a sequence — from both ends inward, or at different speeds. Turns nested loops into a single pass. The tell is a sorted array, a palindrome, or a pair/triplet that must satisfy some condition.

  2. Sliding window

    A window that expands on the right and contracts on the left, maintaining some invariant. The signal is "longest / shortest / maximum substring or subarray satisfying X". Fixed-size and variable-size windows are two distinct templates worth memorising separately.

  3. Prefix sum & difference arrays

    Precompute cumulative totals so any range query becomes a single subtraction. The inverse — a difference array — lets you apply many range updates in O(1) each and reconstruct the result once at the end.

  4. Intervals

    Sort by start (or by end, for greedy scheduling), then sweep once merging or counting overlaps. Shows up constantly in real systems too — calendar booking, seat holds, rate-limit windows — so it connects straight to the system design track.
