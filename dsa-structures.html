Linear Structures — 4 topics

  1. Linked list

    Pointer manipulation under interview pressure: reversal, cycle detection with fast/slow pointers, merging, and the dummy-head trick that removes most edge cases. The doubly linked list plus hash map is exactly how an LRU cache is built.

  2. Stack & monotonic stack

    A stack handles anything with nesting — parentheses, expressions, undo. The monotonic stack is the advanced form: keep elements in sorted order as you scan, and "next greater element" style problems collapse from O(n²) to O(n).

  3. Queue & deque

    FIFO processing, and the double-ended queue that makes sliding-window maximum linear. collections.deque gives O(1) appends and pops at both ends — using a list instead is the most common accidental O(n²).

  4. Heap / priority queue

    When you need the smallest or largest element repeatedly but don't need full ordering. The "top K" pattern, the two-heaps trick for a running median, and merging k sorted sequences all reduce to this. Python's heapq is a min-heap — negate for a max-heap.
