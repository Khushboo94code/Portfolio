Undoing things

The table to memorise. The difference between reset and revert: reset rewrites history, revert adds a commit that undoes one.

SituationCommand
Unstage a filegit restore --staged file
Discard local changes to a filegit restore file
Undo last commit, keep changes stagedgit reset --soft HEAD~1
Undo last commit, keep changes unstagedgit reset --mixed HEAD~1
Undo last commit, destroy changesgit reset --hard HEAD~1
Undo a pushed commit safelygit revert SHA
Change the last commit messagegit commit --amend
Save work temporarilygit stash then git stash pop
Remove untracked filesgit clean -fd
Recover a deleted branchgit reflog then git switch -c br SHA
