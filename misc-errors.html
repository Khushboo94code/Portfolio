Shell exit codes

Anything above 128 means the process was killed by signal N − 128.

CodeMeaningTypical cause
0Success—
1General errorCatch-all failure
2Misuse of builtinBad shell syntax or arguments
126Not executablePermission denied on the file
127Command not foundTypo, or binary not on PATH
130SIGINT (2)You pressed Ctrl-C
137SIGKILL (9)OOM killer — the usual container culprit
139SIGSEGV (11)Segmentation fault
143SIGTERM (15)Graceful shutdown requested (deploy, docker stop)

Network & system errno

These surface as Python OSError subclasses and in strace output.

ErrorMeaningWhat to check
ECONNREFUSEDNothing listeningWrong port, or the service is down
ECONNRESETPeer closed abruptlyUpstream crashed or a proxy timed out
ETIMEDOUTNo response in timeFirewall dropping packets, or an overloaded host
EADDRINUSEPort already boundOld process still running — lsof -i :8000
EPIPEWrite to a closed socketClient hung up before you finished responding
ENOENTNo such file or directoryBad path — the most common error in existence
EACCESPermission deniedFile mode or ownership; binding a port under 1024
EMFILEToo many open filesFile-descriptor limit — raise ulimit -n or leaking sockets
ENOSPCNo space left on deviceDisk full, or inotify watch limit reached

PostgreSQL SQLSTATE

Django raises these as IntegrityError and friends; the code tells you which constraint actually failed.

CodeNameMeaning
23505unique_violationDuplicate value for a unique constraint
23503foreign_key_violationReferenced row does not exist, or is still referenced
23502not_null_violationNULL into a NOT NULL column
23514check_violationA CheckConstraint rejected the row
40001serialization_failureConcurrent transaction conflict — safe to retry
40P01deadlock_detectedTwo transactions waiting on each other; one was killed
53300too_many_connectionsConnection limit hit — you need a pooler
57014query_canceledStatement timeout exceeded
