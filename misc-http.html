HTTP Status Codes

What to return and what a response is telling you. The ones people get wrong are 401 vs 403, 400 vs 422, and 502 vs 503 vs 504.

HTTP Codes Error Codes Shell Python & Django Redis SDLC & Agile

Reference — 26 entries

2xx — Success

CodeMeaningUse it when
200 OKRequest succeededStandard success with a body
201 CreatedResource createdPOST created something — return its Location
202 AcceptedAccepted, not yet processedYou queued the work (Celery) and will finish later
204 No ContentSuccess, no bodyDELETE succeeded, or a PUT with nothing to return
206 Partial ContentRange servedResumable downloads / video seeking

3xx — Redirection

CodeMeaningUse it when
301 Moved PermanentlyPermanent redirectURL changed forever — browsers cache this hard
302 FoundTemporary redirectTemporary move; keep it if you want to count clicks
304 Not ModifiedCache still validConditional GET matched the ETag — no body sent
307 Temporary RedirectTemporary, method preservedLike 302 but POST stays POST
308 Permanent RedirectPermanent, method preservedLike 301 but POST stays POST

4xx — Client error

The client can fix these. Being precise here is what makes an API pleasant to integrate with.

CodeMeaningUse it when
400 Bad RequestMalformed requestUnparseable body, missing required param
401 UnauthorizedNot authenticatedNo or invalid credentials — who are you?
403 ForbiddenAuthenticated, not allowedKnown user without permission — not yours
404 Not FoundNo such resourceAlso used to hide existence from unauthorised users
405 Method Not AllowedWrong verbPOST to a read-only endpoint
409 ConflictState conflictDuplicate create, version mismatch, concurrent edit
410 GoneDeliberately removedResource existed and will not come back
413 Payload Too LargeBody too bigUpload exceeds your limit
415 Unsupported Media TypeWrong content typeSent XML where JSON was expected
422 Unprocessable EntityValid syntax, invalid dataParsed fine but failed business validation (DRF default)
429 Too Many RequestsRate limitedInclude Retry-After

5xx — Server error

Your fault. 502/503/504 are the three that show up in an incident, and they mean different things.

CodeMeaningUsually means
500 Internal Server ErrorUnhandled exceptionA bug — check the traceback
501 Not ImplementedMethod unsupportedServer does not know this verb at all
502 Bad GatewayBad upstream responseNginx reached Gunicorn but got garbage / a crash
503 Service UnavailableNo capacityNothing is listening, or you are shedding load
504 Gateway TimeoutUpstream too slowBackend exceeded the proxy timeout — usually a slow query
