Environments & packages

CommandDoes
python -m venv .venvCreate a virtual environment
source .venv/bin/activateActivate it
pip install -r requirements.txtInstall from a lockfile
pip freeze &gt; requirements.txtRecord exact versions
pip list --outdatedWhat could be upgraded
python -m pip install -U pipUpgrade pip itself, safely

Django management

Run check --deploy before every launch — it catches insecure settings you will otherwise ship.

CommandDoes
django-admin startproject cfg .New project in the current directory
manage.py startapp nameNew app
manage.py runserver 0:8000Dev server, reachable from outside
manage.py makemigrationsGenerate migrations from model changes
manage.py migrateApply migrations
manage.py showmigrationsWhat is applied and what is pending
manage.py sqlmigrate app 0003Show the SQL a migration will run
manage.py createsuperuserAdmin user
manage.py shell_plusShell with models imported (django-extensions)
manage.py dbshellDrop into psql for this database
manage.py collectstaticGather static files for production
manage.py check --deployAudit settings for production readiness
manage.py testRun the test suite

CommandDoes
