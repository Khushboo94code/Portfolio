Files & navigation

CommandDoes
ls -lahLong listing, hidden files, human-readable sizes
cd -Jump back to the previous directory
cp -r src dstCopy a directory recursively
mv a bMove or rename
rm -rf dirDelete recursively, no prompts — check twice
ln -s target linkCreate a symlink
tree -L 2Directory tree, two levels deep

Finding things

CommandDoes
find . -name "*.py"Find by filename pattern
find . -type f -mtime -1Files modified in the last day
grep -rn "text" .Recursive search with line numbers
grep -i -E "a|b" fCase-insensitive regex search
which pythonWhich binary a command resolves to
history | grep gitSearch your shell history

Text processing

The classic pipeline: cut a field, sort it, count duplicates, show the top offenders.

CommandDoes
head -n 20 fFirst 20 lines
tail -f app.logFollow a log as it is written
wc -l fCount lines
sort | uniq -c | sort -rnCount occurrences, most frequent first
awk '{print $1}'Print the first whitespace-separated field
sed 's/old/new/g' fSubstitute text
cut -d, -f2 f.csvTake the second comma-separated column
jq .key file.jsonQuery JSON

Processes

CommandDoes

kill -15 PIDAsk a process to stop gracefully (SIGTERM)
kill -9 PIDForce kill (SIGKILL) — last resort
nohup cmd &amp;Run detached, survives logout
jobs / fg / bgManage background jobs in this shell
