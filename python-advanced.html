  1. Memory, references & garbage collection

    CPython frees objects by reference counting, with a cycle collector for the cases counting cannot handle. Practically this explains memory that never comes back: a global cache, a closure holding a large object, or a reference cycle you created.

    Resources
    Learn
    • gc — garbage collector interface
    • sys.getrefcount
    • tracemalloc — find what is actually allocating
    Practice
    • Create a reference cycle, confirm it is not freed by refcounting, then collect it.
    • Profile memory on a long-running script with tracemalloc.

  2. Descriptors, metaclasses & protocols

    How Django model fields and ORM attributes actually work. A descriptor customises attribute access; a metaclass customises class creation. Rarely what you should write, frequently what you need to read.

  3. Profiling & optimisation

    Measure before you change anything — intuition about Python performance is usually wrong. cProfile for where time goes, timeit for micro-comparisons, and the ordered fixes: better algorithm, better data structure, then C-level libraries.
