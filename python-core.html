Core Language — 6 topics

  1. The data model & everything is an object

    Integers, functions, classes and modules are all objects with types. The data model is the single most useful chapter of the docs. Implementing those protocols on your own classes — __len__, __getitem__, __eq__, operators — now lives in OOP → Dunder Methods.

  2. Built-in data structures

    List, dict, set and tuple, and the cost of each operation. list.insert(0, x) and x in list are O(n) while the set and dict equivalents are O(1) — most accidental slowness in Python code is the wrong container choice.

  3. Mutability, references & copying

    Names are bindings to objects, not boxes holding values. This is why a mutable default argument persists across calls, why b = a on a list aliases rather than copies, and why shallow and deep copies differ.
