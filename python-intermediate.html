  1. Decorators

    A decorator is a function taking a function and returning a replacement. Once that clicks, @property, @staticmethod, Django’s @login_required and Celery’s @task all stop being magic. Use functools.wraps so you do not lose the wrapped function’s identity.

  2. Generators & lazy evaluation

    yield turns a function into something producing values on demand, so you can iterate a 10 GB file in constant memory. The same mechanism underlies streaming responses — which is exactly how LLM output reaches a user token by token.
