Data Structures — 5 topics

  1. Strings & counters

    The simplest type, and more capable than it looks: SET/GET for cached blobs, INCR/INCRBY for atomic counters, SETNX for "only if absent", and SET key val EX 60 NX as the one-liner behind locks and limiters.

  2. Hashes

    A map inside a key — ideal for storing an object’s fields without serialising the whole thing. You can read or update one field with HGET/HSET instead of fetching, parsing, mutating and writing back an entire JSON blob.

  3. Lists & queues

    A doubly linked list with O(1) push and pop at both ends. LPUSH plus BRPOP gives you a blocking work queue in two commands — which is essentially what Celery does with Redis as its broker.

  4. Sets & sorted sets

    Sets give membership and set algebra in O(1); sorted sets add a score per member, keeping everything ordered. Sorted sets are the single most useful Redis type — leaderboards, priority queues, sliding-window rate limiters and time-series indexes are all ZADD plus ZRANGEBYSCORE.

  5. Streams & probabilistic types

    Streams are an append-only log with consumer groups — Kafka’s model inside Redis, with acknowledgement and replay. The probabilistic types trade exactness for memory: HyperLogLog counts uniques in kilobytes, Bloom filters answer "definitely not present".
